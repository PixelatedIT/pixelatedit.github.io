Free & Open Source · Windows

Non-destructive RAW editing.
Free. Open. Yours.

Open LightRoom is a free, open-source, non-destructive photo color-grading application for Windows — built for photographers who want professional-grade RAW editing without a subscription, a license key, or a black box.

Download for Windows — Free View source on GitHub
Why Open LightRoom

Professional RAW editing has been dominated for years by paid, closed-source software — subscriptions, license servers, and tools you can use but never truly own. Open LightRoom is PixelatedIT's answer to that: a real, working alternative built from the ground up, with a non-destructive layer engine, genuine RAW decoding, and a physically-accurate color pipeline — released free and open source, so anyone can use it, inspect it, and help build it further.

It's not a toy or a tech demo. Every tool below is a real, tested, working feature — not a mockup.

Real RAW editing, not just previews

Import RAW files straight from your camera — Canon (CR2/CR3), Nikon (NEF), Sony (ARW), Adobe DNG, Fujifilm (RAF), Olympus (ORF), Panasonic (RW2) — decoded with LibRaw, the same open-source RAW engine trusted across the photo industry. JPEG, PNG, TIFF, BMP, and WEBP are supported too, with embedded ICC color-profile handling so colors stay accurate on import.

Non-destructive, always

Nothing you do is ever baked into your photo until you explicitly export it. Every adjustment lives as its own layer on top of an untouched original — reorder, disable, or delete any of them at any time. Full undo/redo history, saved and reopened exactly as you left it via project files.

A complete color-grading toolkit

  • Exposure, Contrast, Highlights, Shadows, Whites, Blacks, Brightness
  • White Balance — Temperature & Tint, plus a click-to-sample eyedropper
  • Vibrance, Saturation, Hue
  • 8-channel HSL grading, per color
  • Color Wheels — Shadows, Midtones, Highlights, Global
  • Point curve and parametric curve tone control

Local adjustments & masking, done properly

  • Brush, Radial, Linear Gradient, Rectangle, Ellipse, Polygon masks
  • Color Range and Luminance Range masks
  • Skin-tone detection for portrait work
  • Add / Subtract / Intersect, invert, feather, blur, density controls
  • Live on-canvas overlay while you shape a mask

Composition tools

Crop, straighten (just drag along a horizon line), rotate, and flip — all non-destructive, all reversible.

Presets & scopes

Save any grade as a reusable preset and apply it to future photos in one click. Read your image objectively with a live histogram, waveform, vectorscope, and RGB parade — the same reference tools colorists rely on.

Built for real photo sizes

A dedicated preview-quality setting lets big RAW files stay responsive while you edit — with zero compromise on the final export, which always renders at full resolution regardless of your preview setting.

Free & Open Source

Open LightRoom is, and will stay, free.

The full source code is public on GitHub. You can read exactly how every tool works, verify there's nothing hidden, and — if you want — contribute to it directly. No subscription. No account required to use it. No telemetry phoning home behind your back.

Explore the code on GitHub

What's next

Open LightRoom is under active development. On the roadmap: macOS and Linux builds, and pluggable AI-assisted masking — the Subject and Sky mask tools already exist in the interface today and are ready for a model to be dropped in. It's a young project, and that's worth being upfront about, not something to hide.
