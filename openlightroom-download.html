System requirements

OS Windows 10 (1809+) or Windows 11, 64-bit
Processor Any 64-bit CPU from the last ~10 years
RAM 8 GB minimum, 16 GB+ recommended for large RAW files
Disk space ~500 MB free (portable build is ~280 MB unpacked)
Other Internet connection not required after download — the app runs fully offline

macOS and Linux are not available yet — see the roadmap on the About page.

Installing Open LightRoom

  1. Click a Standalone Installer link above.
  2. Run the installer and follow the setup wizard — Start Menu shortcut, optional desktop icon, and .olrproj project-file association are all offered, nothing is forced on.
  3. Launch Open LightRoom from the Start Menu.

Because Open LightRoom isn't yet digitally code-signed, Windows SmartScreen may show an "Unrecognized app" warning the first time you run it. This is expected for new, unsigned free software and isn't a sign anything is wrong — click More info → Run anyway to continue.

If Open LightRoom won't launch and shows a message about a missing Visual C++ component, install the free Microsoft Visual C++ Redistributable (x64) — most Windows PCs already have this, but a small number don't.
